Эмблемы соперников

Страница для администратора сайта. Выбери матч, загрузи оригинальную эмблему клуба и подготовь её к публикации в GitHub.

Сайт работает на GitHub Pages без сервера. Поэтому изображения публикуются через твой аккаунт GitHub, а не напрямую с этой страницы. Пароль или токен GitHub вводить здесь не нужно.

Имя файла: rksh.webp

Выбери файл для подготовки.

Предпросмотр эмблемы

Размер подготовленного файла: 400 × 400 пикселей, формат WebP. Эмблема вписывается целиком, без обрезки.

Скачать подготовленную эмблему Открыть загрузку в GitHub Посмотреть матчи
  1. Выбери нужный матч и исходное изображение. Используй только подлинную эмблему конкретной команды.
  2. Нажми «Скачать подготовленную эмблему». Ей автоматически назначится правильное имя, например rotor-d.webp.
  3. Нажми «Открыть загрузку в GitHub», войди в свой аккаунт и перетащи скачанный файл в папку assets/opponents/. Если файл с таким именем уже есть, замени его через GitHub.
  4. Подтверди изменение («Commit changes») в ветке main. После публикации GitHub Pages эмблема появится у выбранного матча. При необходимости обнови страницу через Ctrl+F5.

Файлы с оригинальными разрешениями храни отдельно. Подготовка копии не меняет исходное изображение на твоём устройстве.
