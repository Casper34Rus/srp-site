# Эмблемы соперников на странице знаковых матчей

Для каждого выбранного матча предусмотрена одна эмблема конкретного соперника. Файлы хранятся в репозитории сайта и публикуются через GitHub Pages.

**Подготовка и загрузка:** открой [страницу управления эмблемами](https://srp-vlg.ru/admin-opponent-logos.html), выбери матч, загрузи оригинальный PNG/JPG/WebP, скачай подготовленный файл и отправь его через GitHub в папку `assets/opponents/`. Для записи в репозиторий нужен доступ к аккаунту GitHub. На самом сайте токены и пароли не используются.

Имена файлов WebP (по одному на команду):
- `rksh.webp` — Русская классическая школа / РКШ (уже добавлен оригинал от пользователя)
- `spartak-junior.webp` — Спартак Юниор (Чёрные)
- `rotor-d.webp` — Ротор Д
- `forward-mikhaylovka.webp` — Форвард (Михайловка) (уже добавлен оригинал от пользователя)
- `academy-rotor-2016.webp` — Академия Ротор 2016, 05.09.2026, ничья 5:5
- `kilikia-yerevan.webp` — Киликия (Ереван)
- `stalingrad.webp` — Сталинград

Не используйте эмблемы других команд с похожими названиями. Логотип взрослого «Ротора» не обязательно совпадает с эмблемой «Ротор Д». Для неустановленных логотипов на сайте отображаются нейтральные инициалы.

Файлы, переданные пользователем в чате, были уменьшены для быстрой загрузки карточек, без изменения символики и текста.

Полная спортивная база, расчёты и данные матчей не зависят от наличия изображений.
