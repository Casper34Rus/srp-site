# Сайт «Спорт-Ревю Поволжья»

Публичный статический сайт. Публикация через GitHub Pages: не переносить файлы страниц, стили и ресурсы без проверки всех относительных ссылок.

## Карта проекта

| Путь | Содержимое |
| --- | --- |
| `index.html` | Главная страница |
| `about.html`, `contacts.html` | О школе и контакты |
| `app.html` | Страница платформы «ФутСфера» |
| `matches.html`, `stats.html`, `tournaments.html`, `nominations.html`, `hall.html` | Страницы футбольной Летописи |
| `football-*.html`, `reports.html` | Дополнительные публичные страницы |
| `privacy.html`, `consent.html`, `publication-consent.html` | Политики и согласия |
| `css/` | Стили сайта и адаптивная вёрстка |
| `js/` | Скрипты сайта, включая отображение матчей |
| `assets/` | Опубликованные изображения, шрифты и иконки |
| `docs/` | Публичные документы организации |
| `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml` | Настройки адреса, индексации и публикации |

## Где хранятся рабочие материалы

- `D:\projects\srp_site` — единственная локальная рабочая копия сайта.
- `D:\projects\srp_united` — мобильное приложение, **другой репозиторий**.
- `D:\projects\SRP_Backups` — резервные копии и исходные архивы медиа вне GitHub.
- `D:\projects\SRP_Scripts` — разовые патчи и технические материалы вне GitHub.

Перед публикацией выполнить `python scripts/verify_local_links.py`: проверяются относительные ссылки HTML/CSS и наличие локальных ресурсов. Это не замена проверке поведения JavaScript и внешних страниц. Изменения на сайте проверять по ссылкам, ресурсам и Git перед отправкой. Не публиковать локальные резервные копии, SQLite, дампы, приватные ключи и технические отчёты. `assets/coach.jpg` и `assets/logo.jpg` используются как запасные изображения и должны оставаться доступными.

В `assets/hall/` находятся опубликованные изображения зала достижений; исходный архив `srp_hall_backgrounds.zip` сохранён отдельно в `SRP_Backups/site-source-archives` и не требуется браузеру. Архив в истории Git остаётся доступным в старых коммитах.
